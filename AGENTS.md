# Agent notes

This is a two-hour take-home on the existing single screen. Read `README.md` and `DECISIONS.md` before changing structure.

## Stack

Expo SDK 58, React Native 0.88, TypeScript. Entry is `index.ts` → `App.tsx` → `src/screens/TrackerScreen.tsx`. Do not migrate this exercise onto Expo Router. There is one screen and the Jest tests mount `TrackerScreen` directly.

`ios/` and `android/` are generated by Expo. Do not add them. Libraries already in the project (`@shopify/flash-list`, `react-native-reanimated`, `react-native-gesture-handler`, `@react-native-async-storage/async-storage`, `zustand`) run in Expo Go. Install anything new with `npx expo install`.

## Feed

The book comes from `mockStream` (`src/stream/MockStreamService.ts`). Keep `subscribe` / `start` / `stop` / `pause` / `resume`, reload items from `getSeedItems()` when the scenario changes, and keep the testIDs listed in `README.md`.

A tick with `sequenceId <= item.sequenceId` is ignored.

## Checks

```bash
npx tsc --noEmit
npm test
```

`npm test` is the smoke test in `__tests__/TrackerSmoke.test.tsx`. Do not weaken it to make a change pass.
